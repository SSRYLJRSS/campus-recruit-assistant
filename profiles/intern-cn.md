# 工作流档：实习（intern-cn）

> 适用于日常实习 / 暑期实习投递（在校生，尚无或仅有 1 段实习）。
> 本档覆盖 `references` 默认值；未列出的项仍按默认执行。

## 结构（与校招档的差异）

| 项 | 本档规定 | 与默认档的差异 |
|---|---|---|
| 头部 | 三行：姓名 / 电话+邮箱 / 学校+专业+**年级** | ✅ 允许写年级（实习按可实习时间筛人） |
| 求职意向 | **可写一行**，含**可实习时间与每周天数** | ✅ 实习 HR 首要筛这个 |
| 段落 | 实习经历（若有）→ **项目/课程项目** → 校园经历 → 自我评价 | ✅ 无实习时课程项目可顶到最前 |
| 页数 | **1 页** | 同默认 |
| 技能段 | 不单设（融进叙事） | 同默认 |

## 核心差异：课程项目 = 迷你实习

在校生最大的资产不是实习，是**能证明能力的课程项目/竞赛/自主项目**。

- 每个课程项目按 STAR 写：课题背景 → 你负责的部分 → 方法/工具 → 结果（分数/排名/被采用/数据量）
- 毕设可写（标注进度，如「进行中，已完成数据采集 200+ 样本」）
- 竞赛写名次与参赛人数（如「省赛第 6 / 120 队」），不写"参与"
- 大作业若只有个人完成，明确写「独立完成」，不要模糊成"团队"

## 自我评价

- 一段话、不分点、**120-160 字**（本档覆盖默认值；该例外已在 `references/16-自我评价.md` 登记）
- 三句式改为：①可用时间与地点（能来几天、能来多久）②一个能上手的能力证据 ③学习速度与留用意愿
- **必须答清"能实习多久"**——这是实习简历被筛掉的第一原因，不写等于让 HR 猜

## 取舍规则

| 有实习 | 无实习 |
|---|---|
| 实习占 2/3，课程项目挑 1-2 个 | 课程项目占主体，校园经历补位 |
| 实习内容写业务结果 | 项目内容写方法与数据 |

- 学生会/社团经历只留能量化的（带过几人、办过几场、拉到多少赞助）
- "熟悉 Office"这类技能不写

## 面试重点

- 双人设：**HR 面**（时间/稳定性/动机）+ **业务面**（基础能力/学习速度）
- 题库必加：**为什么选这个岗 / 能实习多久 / 一周几天 / 和课程冲突怎么办 / 有没有转正意愿**
- 高频命门：课程项目是不是你独立做的、能不能讲清技术细节

## 与默认值的差异汇总

1. 允许年级行、求职意向行（含可实习时间）
2. 课程项目可排到实习之前
3. 自我评价 120-160 字，首句答"能实习多久"
4. 面试必答时间与稳定性问题
