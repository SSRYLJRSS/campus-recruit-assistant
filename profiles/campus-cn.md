# 工作流档：校招·中文（campus-cn）

> 默认档。适用于中国大陆校招应届生投递（运营/销售/产品/管培/综合类）。
> 本档**覆盖** `references` 的默认值；未列出的项仍按 references 执行。

## 结构

| 项 | 本档规定 |
|---|---|
| 头部 | **三行**：姓名 / 电话+邮箱 / 学校+专业 |
| 求职意向 | **不写** |
| 证件照 | **默认不放**；仅国企/银行/形象岗等 JD 要求时按 `references/40-格式红线.md` §3 放（放则渲染不得漏） |
| 届别/学历行 | **不写** |
| 段落 | 实习经历 → 项目经历 → 自我评价；**无独立教育模块、无技能段** |
| 小标题 | `日期 公司——岗位` 单行 |
| 分点 | `N.点题词：描述。`，每条独占一行，每段 3-5 点 |
| 页数 | **1 页**（硬上限；超页用加一砍一） |
| 字体 | 以 `references/40-格式红线.md` §3 为准：微软雅黑；姓名 24pt；模块标题 12pt；小标题 10.5pt；正文 9pt；联系 9pt |

## 自我评价

- 一段连贯文字、不分点
- 字数：**沿用默认值，见 `references/16-自我评价.md`**（本档不另设）
- 三句式：身份与核心价值 → 差异化方法+最硬问题+量化 → 岗位契合与去向
- 按当次 JD 现场定制，禁止套用母版旧版本

## 项目与素材取舍

| 岗位类型 | 技术/开源项目 |
|---|---|
| 技术/产品岗 | 全启用 |
| AI 应用岗（AI 营销/内容/运营） | 保留段落，**全去技术栈** |
| 门店/零售/健身/实业制造 | **一律砍** |

- 运动类经历：JD 硬性要求或加分项含运动/健身时，析出为独立项目条目 + 自我评价首句打锚点
- 个人实践（投资/自媒体等）：JD 指向该领域且无实习证据时，析出为独立项目条目

## 面试重点

- 双人设：普通面 / 压力面
- 管培生、大厂培训生岗 → 题库必加**群面专项**
- 大厂 → 按 **AI 录制面试**（无追问、一次答对）准备
- 非科班专业质疑、实习留用意向、城市接受度 = 高频必答题

## 与默认值的差异

本档即默认值，无额外覆盖。
