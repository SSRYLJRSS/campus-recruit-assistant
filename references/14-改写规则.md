# 定制改写规则

> 说明：本文出现的公司名、机构名、项目名均为**化名**（不指向任何真实主体），数值为示例值；仅示范"选材与迁移"的思考方式，实际内容一律从 `[档案]` 取，**不照抄、不借用**。

> 用途：Step 4 从母版选材并重构 bullet，产出符合 JD 且 ATS 友好的简历内容。
> 参考：yanliudesign/job-description-skill（三版改写/关键词密度/动词排序）、SankaiAI（防 AI 味）、proficiently（priority-hierarchy）、job-hunt-copilot（选材告知）
> 铁律：**只重构，不捏造**。本文件所有规则都建立在「母版事实」之上，超出母版的内容一律不写。

> 执行依据：本文件 + `15-写作总纲.md`（校招简历操作规则集）。改写手法以本文件为准；口径冲突以 `01-口径总表.md` 为准，并记入该表。

## 一、改写总原则（优先级从高到低）

1. **准确性**：不捏造、不夸大、不假设。数字只可强化呈现方式（加粗/前置），不可改值。
2. **母版取材**：所有内容都能回溯到母版文件（经历/项目/技能库/自我评价）。新增事实 = 先回写母版，再进简历。
3. **关键词原样**：JD 的用词原样使用，不换近义词（JD 写「私域运营」就写「私域运营」，不写「社群维护」）。
4. **影响 > 动作 > 工具**：先写结果/影响，再写动作，工具最后。
5. **待核实字段禁用**：母版标「待核实」的字段/经历，定制时一律不使用——**宁可删整段，不写未核实信息**（核实后再启用）。

## 二、选材规则（Step 4.1）

- 用 JD 关键词 + 母版 bullet 的 `[关键词]` / `[标签]` 检索：优先挑**相关度标签命中**（新媒体/内容/销售/产品）且**量化结果强**的经历。
- 每条选中经历，bullet 保留 2-3 条最强、与 JD 最相关的；其余砍。
- **必须向用户说明**：选了哪些经历/bullet、弃了哪些、为什么（一句话理由）。禁止静默删改。
- 经历顺序按 JD 需求重排：最贴 JD 的排最前（实习经历按相关度而非时间倒序，相关度相当再按时间）。
- **弱相关经历**（如销售岗经历投新媒体岗）：能映射 JD 某条职责 → 保留 1 条、只取相关角度（如「用户洞察」）；纯异质（完全无交集）→ 整段弃用并说明理由。

## 三、关键词规则（Step 4.2）

| 规则 | 要求 |
|---|---|
| 用词 | 必须项关键词**原样**用 JD 的词 |
| 密度 | 每条 Top 关键词在简历出现 **2-4 次**（少了过不了筛，多了像堆砌） |
| 豁免 | 母版无证据的关键词（技能/经历均不体现）→ **不硬凑密度**，列入缺口清单（Step 3），由用户决定补库或放弃 |
| 位置 | 关键词至少要出现在：①经历小标题 ②≥1 条 bullet 正文 ③自我评价首句 |
| 缩写 | 首现双写：搜索引擎优化（SEO） |

- 中文简历同样适用：JD 写「用户增长」就在标题和 bullet 里原样出现 2-3 次。

## 四、bullet 重构公式（Step 4.2 核心）

```
弱：动词 + 对象 + 工具
强：[S/T 可选] + 强动词 + 做什么 + 方法/工具 + 结果（量化或质化兜底）
```

示例（母版素材：经历01 Agent 工作流）：

```
✗ 弱：使用 AI 工作流搭建文案生成工作流（动作+工具，无影响）
✓ 强：搭建 AI Agent 文案工作流并推广给同事，长文案产出 2 篇/日 → 4 篇/日，效率提升 100%+（影响+动作+工具）
```

- **量化优先**：母版 `## 成果数字` 里的数字尽量进 bullet；数字不能改值，但可调整位置（前置更醒目）。
- **任务目标（T）**：母版有明确目标数据才写（如「月度目标 +30%」），无数据不硬造——不新增事实。
- **质化兜底**：确实无数字时，写可验证的质化成果（「方案被团队采纳并实施」「获优秀实习生称号」），禁「大大提升/显著改善/效果不错」。
- **职责罗列验收线**：每条 bullet 必须有结果/产出词；出现「负责 XX」而无数词的条目 → 打回改写。
- **强动词表**（优先）：主导 / 设计 / 优化 / 搭建 / 推动 / 重构 / 促成 / 统筹 / 制定 / 落地 / 联动。
- **禁用词表**：参与 / 负责 / 协助 / 帮忙 / 跟着（除非母版确系辅助角色——真实性优先；如经历03「负责校招板块」→ 改写「主导校招板块：对接 50+ 家企业 HR，落地数十场宣讲会全流程」）。
- 中文场景注意：动词+量化对齐 JD 的职责动词，JD 用「运营」就写「运营」，JD 用「策划」就写「策划」。

## 五、篇幅与裁剪

- **页数按 profile**：campus-cn / intern 1 页、campus-tech 1-2 页（见 `profiles/*`；实习经历 3 段 + 项目 1 个时 1 页可放下）。
- **加一砍一**：每加一条强 bullet，删一条同长度弱 bullet；优先砍：与 JD 无关的经历整段、无数字的泛泛 bullet、重复表述。**豁免**：母版弹药不足（可复用 bullet <8 条）时免于强砍，优先保证覆盖 JD 必须项关键词。
- 自我评价：一段连贯文字、不分点，三句式按当次 JD 现场定制；**字数口径见 `16-自我评价.md`**（本文件不重复登记）。

## 六、防 AI 味（SankaiAI + 常识）

| 禁止 | 示例 | 替代 |
|---|---|---|
| 模板腔 | 「具备较强的沟通能力」 | 用经历证明：跨岗对接剪辑 20+ 条成片交付 |
| 空话动词 | 「负责相关工作」 | 具体动作 + 数字 |
| 形容词堆砌 | 「认真负责、积极主动」 | 删除，用行为证明 |
| 中式英文/生硬翻译 | 中文简历混入英文术语 | 统一中文，术语用 JD 用词 |

## 七、自检

不自带清单。改完统一跑 `44-自检清单.md` 的 A（内容）+ C（合规）两块；本文件只管"怎么改"，不管"怎么验"，避免两处口径打架。

## 八、示例：同一素材按不同 JD 重构（演示「挑选+重构+强调」）

> 母版素材（经历01）：月产 10+ 篇百万播放文案；500 万+ 播放 3-4 篇；数据复盘驱动迭代；Agent 工作流提效 100%+；跨岗协作剪辑。

| 岗位 | 保留 bullet | 重构侧重点 |
|---|---|---|
| 新媒体运营 | 爆款文案（content/results）+ 数据复盘（content/technical）+ 提效（technical/results） | 强调「爆款率」「选题方法论」 |
| 内容运营 | 文案产能 + 选题迭代 + 数据复盘 | 强调「内容体系」「选题-复盘闭环」 |
| 产品经理 | Agent 工作流提效（technical/product）+ 复盘驱动迭代 | 强调「流程优化」「效率工具」 |
| 销售/商务 | 跨岗协作 + 提效成果 | 强调「协作」「交付」 |

> 同一事实、不同讲法；四列全部可回溯到母版同一段经历。
