# 简历写作指导方案（校招版 · 现行操作规则集）

> 说明：本文出现的公司名、机构名、项目名均为**化名**（不指向任何真实主体），数值为示例值；仅示范"选材与迁移"的思考方式，实际内容一律从 `[档案]` 取，**不照抄、不借用**。

> 定位：定制阶段"怎么做"的操作规则集。
> 上游依据：用户《优秀简历深度研究报告》(2026-08-03，含判例/ATS 原文/国际对比) + 2026-08 四轮外部调研 + 母版铁律。
> 适用：校招应届、中文简历、单页、方向不定（新媒体/内容/销售/产品/技术管理）。
> 结构红线以 `40-格式红线.md` 为准，自我评价以 `16-自我评价.md` 为准，本文件负责模块写法与规格。

---

## 一、总纲（一切规则的前提）

1. **简历不是个人档案大全，而是「围绕目标岗位的证据集合」**。HR 平均只看 6-10 秒（校招季日均 200-500 份），前 6 秒决定是否继续看。每一行都要回答"我能解决这个岗位的什么问题"。
2. **真实性铁律（法律红线）**：适度美化（把做过的事写精炼、写突出）允许；虚构/夸大技能等级/假学历证书 = 依《劳动合同法》第 26 条构成欺诈，合同可无效，被解雇且无赔偿（有真实判例）。母版没有的事实，定制时一个字不写。
3. **母版唯一**：一切定制从母版取材（挑选 + 重构 + 强调），不新造事实。
4. **校招规格**：按 profile 页数（默认 1 页，campus-tech 1-2 页，见 `profiles/*`）。"简练表达自己"本身就是招聘方看重的沟通效率。

## 二、总体规格

| 项 | 规则 |
|---|---|
| 页数 | 默认 **1 页**（campus-cn/intern 1 页、campus-tech 1-2 页，见 `profiles/*`）；超了用「加一砍一」压缩 |
| 结构顺序 | 头部（姓名 / 电话+邮箱 / 学校+专业 三行）→ 实习经历 → 项目经历 → 自我评价；**无独立教育模块、无技能段** |
| 篇幅分配 | 经历主体占 2/3 以上；自我评价一段话（字数见 `16-自我评价.md`） |
| 排序 | **全篇按时间倒序**（最新在前，实习/项目同规则）；bullet 取舍按 JD 相关度 |
| 语言 | 动词开头，**不写主语「我」**；无中英文标点混用 |
| 格式 | **默认只输出 MD**；DOCX/PDF 由用户用 WPS/Word 转换，或用 `scripts/` 工具链生成 |

## 三、模块写作规则

### 1. 个人信息
- 必填：姓名、手机（24h 可接通）、邮箱。**不写求职意向**（结构红线），不写证件照、不写"届/学历"行。
- 电话纯数字、不加横杠（值取自 `[档案]\01_个人信息.md`，技能内不写死）。
- 隐私红线：婚姻、家庭、身份证号、父母信息、家庭住址一律不写。
- 邮箱：建议用 163/Gmail 等专用求职邮箱；QQ 邮箱前缀含英文名尚可，纯数字/昵称不专业。

### 2. 教育信息（并入头部第三行）
- 一行放完：学校全称 + 专业（格式：`毕业学校：<学校>　专业：<专业>`，值取自 `[档案]\02_教育背景.md`）。
- **不写 GPA / 排名**：排名靠后（如后 50%）写出来是减分项；只有排名靠前才值得写。
- 荣誉（排球省赛等）不单设行：按 JD 需求并入对应经历或自我评价，JD 无关则不占篇幅。

### 3. 实习经历（主体，占 1/2 以上）
- 每条经历 2-4 句、至少 1 个量化数字；分点数量与行数见 `40-格式红线.md`（结构红线）+ `44-自检清单.md`（落盘勾选项），本文件不重复登记。
- **STAR 精简版**：S 情境（挑战性）/ T 任务（可衡量目标，母版有数据才写）/ A 行动（强动词 + 方法工具）/ R 结果（量化，无数字用可验证质化成果兜底）。
- **强动词表 / 禁用词**：见 `14-改写规则.md` §四（改写手法唯一权威，本文件不重复登记）。
- **职责罗列 = 头号死因**：每条 bullet 必须有结果/产出词。
- 软技能用事例"演"：写"对接谁/协调什么/解决什么"，不写"沟通能力强"。

### 4. 项目经历（弥补实习空白 / 突出能力）
- 格式：项目名 + 规模（人数/数据量）+ 角色 + 核心挑战 + 量化结果。
- 挑 2-4 个最相关详写；**课程项目/竞赛/个人项目 = "迷你实习"**（某专业课程设计、调研报告、数据项目可直接补"政策研究/数据分析/报告撰写"缺口）。
- 技术/开源项目启用与否按三档规则：技术产品岗全启用 / AI 应用岗保留段落去技术栈 / 门店零售健身实业一律砍。

### 5. 自我评价
见 `16-自我评价.md`（结构、句式、字数口径的唯一权威）。摘要：一段连贯文字、不分点、三句式（身份价值 → 差异化方法 → 契合去向）、按 JD 现场定制。

## 四、STAR / bullet 写法

bullet 公式、强动词表、禁用词、量化/质化兜底与正反示例，**唯一权威见 `14-改写规则.md` §四**；模块级分点数量与行数见 `40-格式红线.md` / `44-自检清单.md`。本文件不重复登记，避免两处口径漂移。

## 五、排版 / ATS / 投递动作（不在本文件重复定义）

这三块各有唯一权威，本文件不再复写，防止同一规则两处漂移：

## 六、期望薪资（个人字段，不代判）

- 应届推荐**区间式**（如 `10-13k/月`，跨度 20-30%）；或按行业 50 分位；央国企/结构复杂岗写「面议」。
- 不写「无要求」（显无认知）；不附加条件（「低于 XX 勿扰」带情绪）。
- 具体数值由用户提供，缺失时标「待确认」，不替用户编造；本技能不代判个人期望值。

## 七、造假红线

- 判例事实：虚构工作经历（不足 1 年写 2.5 年）试用期被解，索赔被法院全部驳回；虚构学历/证书辞退后索赔均败诉。
- 后果：解雇无赔偿 + 背调（社保/证书）极易揭穿 + 行业口碑受损。
- 结论：能力不足可补，造假是职业生涯不可修复的硬伤。**缺料 → 标缺口，永不硬填。**

## 八、外部调研支撑（2025–2026 · 参考，不改变上文权威）

> 下列为外部公开调研摘要（完整登记见 `_work/research-digest.md`，来源 S1–S16），仅作写作佐证，**不覆盖** 40/14/16/42 等权威文件；冲突时以上述权威为准。

- 一页 A4、单栏、无文本框/分栏/图形、字体 ≤3 种是 ATS 可解析性硬门槛 [S1][S4]。
- 每条 bullet = 动词 + 具体任务 + 量化结果；无真实数据时用规模/周期/覆盖率兜底，**禁虚构百分比**（"效率提升 30%"类会被 HR 识破并视为造假）[S1][S4][S6]。
- 实习 2–3 段最佳，每段 ≥2–3 个月、2–5 条 bullet；公司名后可括注业务线帮助 HR 识别 [S1][S14]。
- 自我评价为可选模块：写不好不如不写；外部通用建议 80–120 字、三公式择一（本技能以 `16-自我评价.md` 为准，通常更详细，属强化版）[S6]。
- ATS 已从关键词计数转向**语义匹配**：按简历↔JD 向量相似度排序，前 20–30% 进 HR；权重示例 必备 45 / 加分 25 / 软技能 15 / 业务 15 → 从 JD 抽"实体 / 关系 / 属性"自然嵌入，优于机械堆词 [S7]。
- 趋势：2025 年约 66.7% 校招生用 AI 写简历、2026 预计 95%，同质化严重 → 差异化靠**真实量化成果 + 人岗匹配**，不靠模板堆词 [S8][S9]。
- 通过率：头部大厂简历通过率约 5%–15%，HR 初筛 3–5 秒（宽口径 10–30 秒）→ 前 1/3 与首条 bullet 决定生死 [S10][S4]。
