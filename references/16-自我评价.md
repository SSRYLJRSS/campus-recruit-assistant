# 自我评价写法（现行唯一口径）

> 说明：本文出现的公司名、机构名、项目名均为**化名**（不指向任何真实主体），数值为示例值；仅示范"选材与迁移"的思考方式，实际内容一律从 `[档案]` 取，**不照抄、不借用**。

> 定位：HR 扫简历的**第一个段落**，6-10 秒决定是否继续看。它是**精简版推销词**，不是履历复读机。
> 三条硬指标：真实 · 针对性（按 JD 现场定制）· 差异性（只有你能说出的东西）。

## 一、结构与措辞（两层叠用）

**层 1 — 三句式（结构）**

```
句1 身份与核心价值 = 最能打的标签 + 角色 + 关键数字（首句埋 JD 关键词，ATS 抓开头）
句2 差异化方法     = 你做事的独特方法 + 解决过的最硬的问题 + 量化结果
句3 契合与去向     = 点名 JD 里的培养模式 / 岗位场景 / 城市 + 长期意愿
```

**层 2 — 四层骨架（措辞密度）**

| 层 | 作用 | 句式参考 |
|---|---|---|
| ① 身份 + 能力定性 | 冒号前一句定调 | 「…专业背景，具备技术理解与数据驱动分析能力：」 |
| ② 能力证据（专业侧） | 用一件作品证明 ① | 「独立从 0 到 1 全栈开发开源桌面产品，既能听懂客户技术需求，也能讲清产品价值」 |
| ③ 能力证据（业务侧） | 数字前压、短促并列 | 「覆盖直销与渠道分销双通路，统筹数十场宣讲会、对接 50+ 家企业」 |
| ④ 定性收尾 + 去向 | 落到岗位名 + 结果导向收束 | 「…意识经过反复验证，期望在 ToB 销售岗位上持续拿结果」 |

**关键**：样板没有一句在复述简历职责——它做的是**能力提炼**（把经历抽象成能力标签），不是经历罗列。三句式管结构，四层骨架管密度。

## 二、三条判据（写之前逐条自问）

| # | 判据 | 不过关怎么办 |
|---|---|---|
| 1 | **去重测试**：这条信息简历正文有没有？有 → 删 | 只保留"简历没有、但面试官想知道"的信息 |
| 2 | **可移植测试**：换个候选人名字还成立吗？成立 → 重写 | 塞进只有本人能提供的东西（数字起点、做事方法、真实场景） |
| 3 | **稀缺性测试**：这点在同批应届生里稀缺吗？不稀缺 → 换一条 | 把最稀缺的那条提到第一句 |

**优势 = 同批候选人不具备的东西。** 主动声明稀缺性（如"应届生里带过团队的不多，我算一个"）往往比任何形容词都硬。

## 三、硬约束

- 一段连贯文字、**不分点**、**140-180 字**（上限 200）；样板见 §五且均在区间内（超过 200 字一律判「太多」打回）。
- 例外：实习档 `profiles/intern-cn.md` 覆盖为 120-160 字（实习 HR 阅读更快）；其余档同本值。**本文件是字数的唯一登记处**，profile 若改字数须在此登记。
- 禁形容词堆砌、禁履历复读、禁"认真负责/吃苦耐劳"、禁自曝弱项（英语等级等一律不写，没有技能段可以藏，就不写）。
- 必须回应 JD 的软性信号，把母版证据翻译成 JD 语言。
- 每句可回溯母版真实经历。
- **跨域时首句砍掉原赛道标签**（投实业/制造岗不提百万粉账号、达芬奇、爆款文案），只留可迁移能力。
- **压缩顺序**：删铺垫 > 删并列修饰 > 保动词 > 保数字；先砍"做事习惯/方法是"类过渡词，再砍荣誉细节。

## 四、去 AI 味手法

去 AI 味的判据、禁词表与通用手法**唯一权威见 `41-去AI味.md`**（本文件不重复登记禁词表）。落到自我评价段落，额外注意：

- **长短句错落**：把「我做的事大多不在电脑前。」写成独立短句，立刻有节奏；避免每条都是"动词 + 宾语 + 结果"的统一长度。
- **允许口语短句**：「我算一个」「都由我跟」「这两条我都清楚」是人味来源，不是不专业。边界：口语化 ≠ 俏皮（「门道」「摸进门」仍禁）。
- **数字带起点**：「日均 2 篇提到 4 篇」优于「效率提升 100%」。
- **同义不同字**：简历已有「缩短新实习生培训周期」，此处写「新实习生上手时间明显缩短」——因为它在此处是**稀缺性主张**而非经历复述。

## 五、样板

**A. 销售管培生（欧焙食品，175 字）**

> 具备一线执行与客户沟通能力：实习中全程参与线上引流、线下代理与合作商招募，跑通直销与渠道分销双通路，统筹数十场宣讲会、对接 50+ 家企业，从陌生触达到合作落地全流程跟进。习惯先看数据再定动作，实习期复盘内容数据反推选题，所写内容周均 2-3 篇破百万播放。带过团队也带过新人，先立执行标准再带教，缩短新人上手周期；校排球队三年主力，抗压经省级赛事验证。期望从销售一线做起，接受华东大区轮岗与调派，持续拿结果。

**B. 实业/制造业管培生（衡仪制造，A 版）**

> 担任星芒科技校园俱乐部首届部长与校就业促进会部长，从 0 到 1 组建团队、明确分工并组织例会，对接 50+ 家企业、统筹数十场线下活动。带人的方法是先把标准立起来：实习期间制定执行标准与编码规则并带教新人，缩短新实习生培训周期，日常用飞书多维表格与 AI 工作流把团队效率提升 30%-100%，能依据数据复盘定位问题并迭代策略。希望成长为实业管理者，认同 18 个月跨产业轮岗培养，愿意从生产和销售一线做起，先把每个环节的流程与数据吃透，长期在杭州发展。

**仿写取舍纪律**：ToB 销售版可用「技术理解 + 独立全栈开发」层（技术叙事加分）；投**快消/门店/零售/实业**类岗时**必须换掉这一层**——改为「具备一线执行与客户沟通能力」，②层换成带教与数据复盘，保留 ③④ 层。

## 六、常见错误对照（勿再犯）

| ❌ 错误写法 | 为什么错 | ✅ 正确做法 |
|---|---|---|
| 「专业能力：…」「工作经验：…」分区两段 | 按能力类别组织的通用模板，放到任何岗位都成立 = 对该岗位没信号 | 三句式，按 JD 现场定制 |
| 逐条照 JD 铺开 5 点 | 太长，且变成关键词填空 | 归纳成 2-4 个能力组，再压成 140-180 字连贯文字 |
| 把实习职责再念一遍 | 履历复读，零增量，浪费首屏黄金位 | 去过重测试，只留"简历没有但面试官想知道"的 |
| 首句「曾为百万粉泛财经账号供稿」投实业岗 | 带错赛道标签，HR 判错赛道直接出局 | 首句换管理潜质锚点，赛道标签砍掉 |
| 全程不提轮岗、一线、城市 | 没回应 JD 最关心的"会不会干一年就跑" | 句3 点名培养模式 + 一线岗位 + 长期发展地 |
| 写英语等级、性格弱点 | 自我评价点弱项 = 提醒 HR 去筛 | 不写 |
