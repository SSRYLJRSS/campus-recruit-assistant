## 一、发行岗结构速查（面试底层框架）

- 发行 = 把产品触达用户并变现的环节（研发做产品，发行做增长）；常见表述「全链路操盘：渠道策略→发行执行→内容推广→用户增长」
- **三大核心职能（某游戏大厂发行管培生轮岗框架，示例）**：效果买量（UA）/ 内容推广 / 商务采购
- 三职能共同目标：以可量化的方式获取用户、摊薄获客成本、长线变现
- 发行岗 JD 常见必须项：游戏热爱者/深度玩家（**命门题**）、网感+文案创作+短视频策划+新媒体运营、沟通+商务谈判素质、市场敏感度+抗压、逻辑分析+总结规律

## 二、渠道结构（谈渠道策略必背名词）

| 渠道 | 要点 |
|---|---|
| 硬核联盟（华为/OPPO/vivo/小米等） | 2014 年成立，**5:5 收入分成**（「安卓税」），全生命周期抽成；2014-2024 被厂商持续挑战 |
| TapTap / 好游快爆 | 零收入分成（广告+社区变现），垂直游戏社区，厂商绕渠道的重要阵地 |
| 巨量引擎（抖音） | 国内买量主阵地；通过效果广告引导用户绕过应用商店直接下载 |
| 某大厂应用商店 | 该大厂系广告倾向引导至自有商店下载：既收流量费又收渠道分成 |
| 渠道联运 | 渠道供流量曝光、厂商分成（CPS 按充值分成）；联运分包 = 每渠道一个 APK 渠道包，靠签名/参数归因 |

## 三、效果买量核心概念（框架级，够用）

- 指标：LTV（用户生命周期价值）、ROAS（广告支出回报率）、CAC/CPI（获客成本）、DAU/MAU、留存、Cohort 同期群分析、Payback Period（回本周期）
- 链路：广告点击→下载→激活→付费全链路归因；行业痛点 = 买量成本飙升 + 隐私限制 + 黑产（高光激活零付费）
- 素材是买量灵魂（投放素材决定点击转化）
- ⚠️ 面试只考框架理解，不必背公式；LTV/ROAS 权威定义建议面试前从游戏行业垂直媒体补一篇

## 四、派对游戏营销案例（内容推广职能的首选面试案例，示例）

- 成绩（示例，具体以最新公开信息为准）：上线初期创下该厂 DAU 纪录；单月 iOS 收入达数千万美元级；累计注册用户破亿级；短视频话题播放量达千亿级、官方账号粉丝数百万级
- **营销三打法**：
  1. 内容差异化：弱化核心玩法，主打「社交性 + 自制性」（乐园工坊 UGC 地图编辑器 → 全民共创内容反哺声量）
  2. IP 联名生态化：盲盒抽皮肤（潮流文化）+ 游戏内外 IP 联动（动漫/餐饮/潮玩等多品类，示例）
  3. 平台调性定制化：B站（分区运营+中腰部主播测评）、小红书（皮肤/地图审美向）、抖音/快手（追热点造爆款，标志性舞蹈挑战出圈）
  4. 节点营销：春节/元宵关键窗口集中投放
- 竞品对抗：某竞品派对游戏同期上线，首期生态投入数十亿元级（示例）
- 派对游戏爆款逻辑：低门槛（手残党福音）+ 强社交

## 五、某游戏大厂渠道战略（商务采购/渠道博弈的核心弹药，示例）

- **「踢开硬核联盟」**：某体育手游首款不上安卓厂商商店；第三方估算两个月投放数亿元级（示例），七成投安卓、多数流向头部买量平台
- 逻辑：一次性买量取代渠道联运分成 → 赚「长钱」；某大厂系广告非首选（自有应用商店引导+竞对关系）
- TapTap 阵地（零分成）：上线首日热门榜第一、两周数十万级下载（示例）；iOS 连续数日免费榜第一、累计数百万级下载（示例）
- 渠道分成以游戏代币回馈玩家（示例）；该厂高层曾公开质疑安卓分成偏高
- 行业背景：头部开放世界/策略手游自 2020 年起弃传统安卓渠道（示例）；「宣发+渠道费用超研发成本很常见」
- 战略逻辑：有头部爆款托底 → 用非头部游戏试水，稳健又具战略意义

## 七、「游戏热爱者」命门题两版预案（母版无游戏弹药时的处理）

- **有游戏经历版**：深挖真实游玩（品类/时长/深度），展示「玩家视角 + 从业者视角」双视角
- **无游戏经历版（差异化重述）**：不装玩家、不撒谎；定位 = 「我不是最会玩游戏的，但最懂内容怎么让人上瘾」；用派对游戏 UGC 生态案例证明内容与游戏增长强相关；展示已补行业认知（渠道/买量/该厂渠道战略）；核心 = 把「游戏理解」换成「增长理解」
- 该类厂商面试「玩什么游戏」几乎必问（跨岗位验证）；流程信号：笔试→一面（业务）→二面→HR 面
