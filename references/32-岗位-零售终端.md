## 一、岗位本质（先看透这个，再谈准备）

储备店长 ≠ 销售员，也 ≠ 职业经理人。**它的本质是：在品牌方的标准化体系里，通过「人 + 货 + 场」的日常调度，把一个物理空间的销售额做上去。**

三层能力拆解：

| 层 | 内容 | 校招生通常缺什么 |
|---|---|---|
| **人** | 排班、分工、带教、考核、冲突处理、员工稳定性 | 缺「带比自己年长/资历深的人」的经验 → 终面高频考点 |
| **货** | 出样、陈列、库存结构、滞销品处理、产品上下市、主推策略 | 缺门店货品管理的直接经验（几乎所有人都没有） |
| **场** | 门店形象、动线、外立面/橱窗、活动落地、线上线下引流 | 缺「线下流量」概念，但有线上内容经验的人可迁移 |

> **关键洞察**：校招岗默认你没有门店经验（JD 不写「有经验者优先」就是明确信号）。面试官真正筛的是：① 能不能拆经营问题 ② 能不能带人 ③ 愿不愿意扎根一线。

## 二、门店 KPI 框架（背下来，这是「你做过功课」的分水岭）

### 2.1 核心恒等式

```
销售额 = 客流量 × 转化率 × 客单价
```

**业绩不达标时，问题必在三者之一。** 这是所有门店经营分析的第一刀。

### 2.2 三层九指标

| 层级 | 指标 | 公式 | 参考基准 |
|---|---|---|---|
| 流量层 | 客流量 | 统计时段进店人数 | 看趋势 + 看渠道结构 |
| 流量层 | 进店率 | 进店人数 ÷ 路过人数 ×100% | 优质门店 ≥30% |
| 转化层 | 成交转化率 | 成交人数 ÷ 进店人数 ×100% | 零售 15-25%（家居属低频高值，实际更低） |
| 转化层 | 客单价 | 销售总额 ÷ 成交单数 | 提升靠高值推荐 / 套餐设计 |
| 转化层 | 连带率 | 销售总件数 ÷ 成交单数 | 目标 ≥1.8 件/单 |
| 转化层 | 件单价 | 销售总额 ÷ 销售总件数 | 看产品结构（低价走量 vs 高毛利） |
| 人效层 | 人均销售额 | 门店总销售额 ÷ 员工人数 | 衡量团队战斗力 |
| 人效层 | 个人转化率 | 个人成交数 ÷ 个人接待数 ×100% | 精准考核到人 |
| 坪效层 | 坪效 | 门店月销售额 ÷ 门店面积(㎡) | 衡量空间盈利能力 |
| 复购层 | 会员销售占比 | 会员销售额 ÷ 总销售额 | 衡量私域质量 |

### 2.3 口径使用铁律

⚠️ **除公司 JD/年报明确写出的指标外，其余一律用「通用门店经营分析框架」引入，不要说成「贵司的 KPI 是……」**。
- 实证：沐家家居官方口径只在「营销管理」岗 JD 出现过 4 个词 —— **进店率、客单价、产品排行、产品毛利率**。
- 说错口径 = 直接暴露「背了模板没做研究」。

### 2.4 业绩诊断四步法（情景题标准答法）

```
① 定位：用恒等式判断是客流 / 转化 / 客单哪一项塌了（先用数据，不猜）
② 归因：客流 → 场外引流问题；转化 → 话术/动线/产品知识；客单 → 连带/高值主推/套餐
③ 给动作：每项给 2-3 个具体可执行动作（带节奏、带时间）
④ 定衡量：多久看一次、用哪个指标验证动作有效
```

> 通用提醒：情景题易犯「方案泛化（套话、无节奏无数字）」。四步法是解药 —— **必须带节奏（先诊断→再定位→再动作→再衡量）和带数字**。

## 三、家居行业 2026 判断（可复用的分析骨架）

### 3.1 一组硬数据（国家统计局 / 中国建筑材料流通协会口径）

| 指标 | 2026 年 1-6 月同比 |
|---|---|
| 全国房地产开发投资 | -18.0% |
| 新建商品房销售面积 | -11.6% |
| 建材家居卖场累计销售额 | -4.39%（6,640.37 亿元） |
| 家具类社零 | -3.7% |
| 建筑及装潢材料类零售额 | -8.8% |
| 家具规上企业营业收入 | -8.6% |
| 家具规上企业利润总额 | **-52.7%** |
| 家具规上企业营收利润率 | **1.8%** |

### 3.2 两条结构性判断（最有价值，面试中直接用）

1. **存量置换时代已确立**：2026H1 二手房交易占房屋总成交量 **50.4%，首破 50%**；18 个省市二手房交易面积超新房。旧房改造、局部翻新、适老化成为核心驱动力。
2. **品类分化：软体抗跌，定制承压**
   - 定制：深度绑定新房竣工与前装链条 → 双位数下滑
   - 软体：更新周期短 + 绑定二手房交易 + 智能化趋势 + 出口支撑 → 下滑幅度收敛
   - 需求红利集中在**门窗、软体等更换便捷、客单价较低**的品类；全屋定制/地板焕新因工序复杂、改造成本高，难形成规模化增量

### 3.3 政策（2026 版「两新」政策）

- 2026-01-08 发改委 + 财政部发文：政策延续但**范围收缩、门槛提高、权限下放地方，不再普惠式支持**
- **家装品类退出全国补贴清单**；**智能家居（含适老化）新增购新补贴**，地方自主制定标准
- 2025 年国补集中落地提前透支需求 → 2026 年高基数 + 政策退坡

> ⚠️ 引用风险：政策文件未找到官方原文直链，仅由 2 篇上市公司半年报转引 → **表述加「据上市公司公告披露」**，置信度 MEDIUM。

### 3.4 数字冲突警告（别踩）

「2026 年 1-5 月家具类零售额 +14.6%」与「2026 年 1-6 月家具类社零 -3.7%」口径冲突（前者限额以上、后者全口径）。
**面试中只讲方向性结论：软装/软体受益，硬装/定制承压。不引用具体百分比。**

## 四、沐家家居速查

> 复用前请重新验证时效。

### 4.1 基本面

| 项 | 上一年度（示例） | 最近半年度（示例） |
|---|---|---|
| 营收 | 约 180-220 亿（+个位数%） | 约 90-110 亿（个位数波动） |
| 归母净利 | 约 15-20 亿（两位数增长） | 约 8-10 亿（个位数下滑） |
| 门店 | 约 5,000-6,000 家（以经销为主、少量直销） | — |
| 境内 / 境外 | 约各占一半 | 境内两位数下滑 / 境外两位数增长 |

**最关键的一条（示例）**：最近半年**外销占比略超内销，首次过半** —— 内贸承压、外贸撑盘。

### 4.2 战略关键词

- **四支柱战略（示例）**：零售转型、整家突破、全球深化、效率驱动
- **内贸「一体两翼」（示例）**：以主品牌为核心 + 软体业务创新 ＆ 整家业务突破
- **KBS（精益运营体系，示例代号）**：增长飞轮，精益运营 + 结构性降本控费
- **零售转型**：多年前启动、持续投入；已完成零售/会员/流量/仓配服/供应链/商品运营全域数字化底座；落地「销、转、订、收、进、存、发」全链路标准化；**由「搭体系」迈入「深运营」**
- **核心动作**：OMO 全域一体化 + **帮经销商「降包袱」**（低效门店关停、库存结构优化）
- 核心价值观：以用户为中心、以绩效为本、坚持奋斗创新

### 4.3 校招机制（校招培养计划，示例）

流程：**网申 → 线下宣讲 / 线上 AI 初试 → 复试（业务部门面试，面经显示为群面）→ 在线测评 → 终试（高管/HRD）→ OFFER → 签约**

培养：双轨成长通道（专业深耕 + 管理发展）+ **双师陪伴（业务导师带实操 + 成长导师管发展）** + e-learning
薪酬：不同渠道口径不一（示例区间，差异较大）→ **面试中不主动报数字，统一以 JD/官方简章为准**

> ⚠️ 注意区分同名不同主体（上市主体 vs 集团/关联公司）—— 薪资口径可能相差一倍，投递前务必核实主体与岗位。

## 五、沐家面经题型库（跨源归纳，命中率高）

### 5.1 初面（HR / AI 初试）

- 请用**三句话**介绍你自己
- 为什么选择沐家家居？
- **是否能接受外派？对工作地点有什么期待？**（必问）
- **你对家居行业有什么了解？**（必问，需提前准备）
- 依据简历逐条提问
- 跨专业追问实锤：「你非营销专业为什么投营销岗，不选技术类？」

### 5.2 群面（复试，沐家固定环节）

| 题型 | 真题 |
|---|---|
| 排序选择型 | 给一堆词，选出「领导应具备的三个」+「无关紧要的三个」（**答案不重要，重要的是过程**） |
| 方案预算型 | 品牌与大学合作，给几个方案 + 预算，选最能提升形象的几种（8 分钟读题写理由 → 轮流发言 → 自由发言） |
| 辩论型 | 5v5：应届生就业是**平台**重要还是**梦想**重要 |

节奏细节：宣讲会结束即初面 → 一面当晚 22:00+ 发二面通知 → 二面酒店集中一下午（某场次百余人录六成，示例）→ 当晚通知次日复试。

### 5.3 终面（高管/HRD 单面，约 30 分钟，气氛轻松）

高频题：
- 自我介绍 / 说说你对这个岗位的理解
- 大学期间最骄傲的一件事 / 最大挫折及解决
- 与岗位相匹配的能力
- **工作稳定性如何？想做几年就换吗？**
- **和同事发生争吵怎么处理？**
- **如果你是领导，下属和你有矛盾、不听你指挥怎么办？**（两篇面经均出现，命中率最高）
- 对工作不熟悉、大家都很忙，怎么办？
- 还有什么想问我的？

面经原话风格总结：「怎样回答都可以，**只要自圆其说言之有理即可**」→ 逻辑自洽 > 标准答案，但必须有真实经历兜底。

### 5.4 翻车教训（面经实证）

> 「意向不高也没怎么准备，**对公司也没了解**，甚至去年自己写的**简历内容都不太记得了** —— 当晚就收到拒信」

**两条铁律**：① 必须真的了解公司（不是背简介）② 简历上每个字都要能展开讲。

## 六、非营销/管理专业候选人如何回击专业质疑

沐家储备店长 JD 写「市场营销类、管理类、设计类专业**优先**」—— 非此三类专业会被扣分，但这是"优先"不是门槛。

**回击公式**：承认专业 + 用做过的事反证 + 桥接岗位

```
「我的专业是 XX，确实不是营销管理科班。
 但我做过的事就是营销管理：主动向 XX 公司谈下合作（BD），
 从 0 搭起核心团队并明确分工与运营机制（组织），
 把数百人的社群做到高活跃（示例，用户运营）。
 我的专业不是营销管理，但我已经干了营销管理的活。」
```

同理可用于：为什么非营销/管理专业投零售、投营销（面经实证有此追问）。

## 七、跨场景迁移话术库（线上/校园经验 → 线下门店）

> 这是非门店背景候选人最需要的一套桥接句。每题回答结尾主动加一句，把证据"翻译"成门店语言。

| 已有证据 | 桥接句 |
|---|---|
| 内容爆款 / 百万播放 | 「内容漏斗（曝光→点击→停留→转化）和零售漏斗（客流→进店→成交→客单）是同一套拆解逻辑」 |
| 社群运营（示例：数千人） | 「门店的会员私域和社群是一样的：规则 + 分层 + 模板化响应，靠机制不靠人盯」 |
| 统筹数十场活动（示例） | 「门店也是多线并行——客流高峰排班、活动落地、投诉处理同时发生，练的就是这种调度」 |
| 从 0 到 1 建团队 | 「接手门店先搭班子、再定分工、再做标准化，和我建俱乐部是同一套顺序」 |
| SOP 缩短新人培训周期 | 「门店导购流动率高，最有效的办法就是把优秀导购的动作拆成 SOP，让新人照做一遍就上手」 |
| AI 工具 / 数字化提效 | 「先做减负再谈工具 —— 先帮他省出时间，再让他用新东西」 |
| 主动 BD 合作 | 「品牌方和终端伙伴怎么协同，我在俱乐部里和品牌方协同过，逻辑相通」 |

## 八、本题库的 GAP（复用时需补的研究项）

| # | 缺口 | 补法 |
|---|---|---|
| 1 | 目标城市的具体门店数量/位置/店态 | 实地逛店，记录动线/出样/导购话术/客流 |
| 2 | 储备店长的晋升路径与时间线 | 宣讲会现场问 HR（沐家宣讲会开放提问） |
| 3 | AI 初试题型与时长 | 网申后系统内查看；搜「{公司} moka AI 面试」 |
| 4 | 企业文化官方表述原文 | 官网 + 年报致股东信 |
| 5 | 内贸组织架构（事业部/区域分公司/经销商权责） | 宣讲会问业务面试官 |
