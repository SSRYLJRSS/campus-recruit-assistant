# 复盘规则

> 用途：Step 5 面试结束后出复盘报告（面试官 → 教练人格切换后执行）。
> 参考：JunhaoXue/interview-mentor-skill（5 维评分 + 根因诊断）、open-career-skills（structure/specificity/ownership/quantification）、job-hunt-copilot（友好复盘）。
> 原则：**只评价回答，不评价人**；每个分数必须能指出具体证据（哪题、哪个回答片段）。
> 5 维分是**全场面上的汇总分**（以高频证据定档，不逐题平均）；每题点评标注其贡献了哪些维度。

## 一、5 维评分（每维 1-5 分，附档位描述）

| 维度 | 问的是 | 5 分标准 | 3 分标准 | 1 分标准 |
|---|---|---|---|---|
| **Substance 实质** | 有没有真材实料 | 具体细节 + 方法 + 数字，可验证 | 有内容但细节/数字不全 | 空话、套话、概念堆砌 |
| **Structure 结构** | 讲得清不清楚 | STAR 完整，逻辑清晰，详略得当 | 有逻辑但顺序/详略欠佳 | 混乱、跑题、东拉西扯 |
| **Relevance 相关性** | 答没答到点上 | 直接回应面试官问题 + 挂钩岗位 | 部分相关，有废话 | 答非所问，自说自话 |
| **Credibility 可信度** | 听起来真不真 | 有基数、口径、对比，边界清晰 | 有数字但说不清来源 | 「我们」「大概」「应该」堆砌，数字无出处 |
| **Differentiation 差异化** | 凭什么选你 | 有独特视角/不可替代的点，与岗位强关联 | 有亮点但不够独特 | 换成任何候选人都能说 |

```
总分 = (Substance + Structure + Relevance + Credibility + Differentiation) / 5
档位：4.5-5.0 强面 / 3.5-4.4 稳面 / 2.5-3.4 及格线 / <2.5 需补强
```

### 评分校准机制（防虚高/虚低）

- 教练先给分 + 依据 → **用户可否决并修正** → 修正记录进薄弱点库（自校准，越用越准）。
- 首次复盘标注「初评分，尺度待校准」；跨面试对比看同维度趋势，不跨人设直接比总分。

## 二、每题点评格式（逐题，不放水）

> 点评前先读 `[面试]\题库\` 对应主题的「理想答案要点」，对照差距点评，不凭印象。

```
### Q4（经历深挖·Agent 工作流）— 压力面追问到 L4 数字层
- 考察维度：Action + Result ｜ 关联 5 维：Substance / Credibility
- 你的回答要点：[摘录用户原话 1-2 句]
- ✅ 做得好：…
- ⚠️ 问题：…（示例：口径不清——只说了「100%」，没讲基线怎么统计的）
- 🔧 改进示范：标准答法「基线是手工写长文案日均 2 篇，接入 Agent 后 4 篇，统计周期 3 个月，稳定后仍保持」→ 为什么这样答（口径+周期+可验证）
```

## 三、面试官内心独白（复盘阶段展示）

- 逐题附一段「面试官内心独白」：如果这是真实面试，面试官此刻在想什么、会怎么判。
- 示例：「他说『我们提升了 30%』，我听到的是『不确定是不是他干的』——大概率接下来会追贡献边界。」
- 目的：让用户学会从面试官视角审自己的回答。
- **生成与展示边界（重要）**：内心独白在面试进行中由面试官人格**即时写入实录文件**（见 20 Step4 实时落盘、22 切换协议），**对用户不可见、面试当场绝不口头透露或暗示评分**；**只在面试结束、切换到教练人格后的复盘阶段才解锁展示**。面试中"不评价"与复盘"给评分+独白"由此衔接：写的是私有记录，看的时机是复盘。

## 四、薄弱点归因 + 入库

面试中所有 ⚠️ 项汇总归因，归因分类：

| 归因类型 | 含义 | 对应动作 |
|---|---|---|
| 素材缺失 | 经历里没有这件事/这个数字（母版没料） | 标记「母版缺细节」→ 回 [档案] 挖掘补库 |
| 记忆模糊 | 有料但答时想不起来（细节没背熟） | 写入薄弱点库，讲稿库补 STAR 讲稿 |
| 表达问题 | 有料但讲不清（结构/详略/术语） | 训练建议：重述练习 + 复盘示范句 |
| 知识盲区 | 行业/岗位知识没准备 | 情报库补充 + 训练计划 |

- 薄弱点库条目格式（数据层 `[面试]\薄弱点库.md`）：

```
| 弱点 | 根因 | 出现次数 | 最近日期 | 训练建议 | 关联出处 |
```

- 跨 2+ 次面试重复出现的弱点 → 升级为「训练计划」（对应 open-career 的 /upskill），下次面试优先出对应题。

## 五、回写判定（Step 6 用，须用户确认）

| 发现 | 是否回写 | 去向 |
|---|---|---|
| 面试答不出但母版其实有料 | 是（挖掘遗漏） | [档案] 挖掘记录补库 |
| 面试中打磨出的好措辞/新角度 | 候选 | 经用户确认回写母版 + 变更记录 |
| 母版确实没有的素材 | 否 | 如实放弃，不编造 |
| 行业知识盲区 | 情报库补充 | 不入母版 |

## 六、复盘报告输出结构

```
# 面试复盘 · 公司_岗位_YYYYMMDD_人设
1. 一句话总评 + 总分（含 5 维分）
2. 每题点评（含改进示范）
3. 面试官内心独白合集（挑 3-5 题）
4. 薄弱点清单（带归因 + 优先级）
5. 训练建议（下次面试前练什么）
6. 补库建议（给 简历阶段的回写清单）
7. 下次建议：换人设？重面薄弱模块？
```

## 七、验收清单

- [ ] 5 维分都有具体证据（引用回答片段）
- [ ] 每题点评含 做得好/问题/改进示范 三要素
- [ ] 薄弱点已归因（素材缺失/记忆模糊/表达/知识盲区四选一）
- [ ] 薄弱点库已更新（新弱点入库、旧弱点计次）
- [ ] 补库建议清单已给出
