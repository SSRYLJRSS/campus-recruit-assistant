# 网申表单字段化输出（2026-08-18 新增，2026-08-18 合并 application-form-fields.md 重复稿）

> 说明：本文出现的公司名、机构名、项目名均为**化名**（不指向任何真实主体），数值为示例值；仅示范"选材与迁移"的思考方式，实际内容一律从 `[档案]` 取，**不照抄、不借用**。

触发场景：用户在网申系统/在线申请表单中需要逐字段填写，而非交付整份简历文件。
实战来源：2026-08-17 抖音单，用户连续问「简单描述非销售相关实习经历 50 字」「简单描述校园实践经历或项目经历」——此前无规则，靠临场手抽，本篇将其固化为可复用打法。

## 核心原则

1. **字段优先于简历**：网申表单要的是「切割好的小段」，不是整份简历。从母版/当日定制 CV 里挑对应弹药，按字段字数上限压缩。同一段经历要出两套话术：简历版（完整 STAR+bullets）vs 网申版（字数内浓缩，一个字段只说一件事，数字优先）。
2. **字数硬约束**：先看字数上限（50/100/200/500 字常见），超限必被系统卡住或截断。压缩优先级：**删场景铺垫 > 删并列修饰 > 保动作动词 > 保量化数字**。数字是最后砍的。**输出后必须数清字数**（Python `len(text)`），超限先砍形容词/副词再砍并列示例，数字保留。
3. **目标字数 = 上限的 80-90%**（50 字限写 40-45 字、100 字限写 80-90 字），留余量给系统标点。同段内容被问多档（50/100/200/500 字）时**由短到长扩展**：先写 50 字版 → 加方法得 100 字版 → 加背景+第二个成果得 200 字版 → 展开细节得 500 字版。
4. **字段语义对齐**：每个字段问的是不同问题——
   - 「实习经历简述」→ 岗位相关度排序，相关度最高的经历放最前
   - 「项目经历简述」→ 从 0 到 1 / 规模 / 成果
   - 「自我评价 / 个人简介」→ 差异化价值主张（参照自我评价铁律：推销词不是履历复读）
   - 「职业规划」→ 目标岗位 + 1 年/3 年递进，别写空话
   - 「为什么选择我们」→ 公司业务 + 岗位 + 你的匹配点（三段式）
5. **诚实红线不变**：与简历同源同一口径，字数压缩只删不编，面试追问得住；字段涉及岗位方向性取舍（如「非销售经历」要看菜下饭剔商务段）时口径与定制 CV 一致，严禁凭空新编。
6. **交付格式**：直接给可复制文本 + 标注字数（如 `42 字`），用户复制粘贴即可。同一母版可生成多档（50/100/200/500 字）供不同系统选用。

## 常见字段模板

### 实习经历简述（50 / 100 字档）

**50 字档**（删岗位铺垫，只留动作+数字）：
> 星屿传媒供稿百万粉财经号，做数据复盘、搭 AI 工作流提效 100%+；衡广文化脚本与飞书自动化。（42 字）

**100 字档**（加方法/工具细节）：
> 星屿传媒：面向百万粉泛财经账号供稿，主题策划→稿件输出→数据复盘定位用户偏好，周均 2-3 篇破百万播放；搭建 Agent 工作流文案产出提效 100%。衡广文化：主导广告脚本创作日均 10+ 条，搭建飞书 AI 自动化系统提升团队效率 30%+。

### 校园实践 / 项目经历（常见网申字段）

> 星芒科技校园俱乐部（从 0 到 1 创建）：主动对接星芒科技谈合作落地，建 300+ 人社群，联动 10+ 所高校。校就业促进会部长：对接 50+ 企业 HR，统筹数十场宣讲会，运营数千人招聘社群。

### 自我评价 / 个人简介（常见 200 字档）

参照母版 06 对应岗位版本压缩；改为**分点短句**组织（写法见 `16-自我评价.md` / `14-改写规则.md`），数字+事实，不堆形容词。弱项（如英语等级）不写。

## 归档

- 常用字段的成品可直接复用，但**每次投递前仍要对齐目标 JD**：岗位关键词要原样用 JD 词（网申系统也可能过 ATS 或关键词筛选）。
- 可考虑在数据层 `[台账]` 台账里为每单附「网申字段速答」节，记录该公司网申系统用到的字段清单，同公司复用直接调档。

## 与本技能衔接

- 定制简历落盘时**顺手预生成一套网申字段包**（50/100/200/500 字各档位的经历/项目/自评），追加在定制说明末尾「网申速填包」小节——用户投递时直接复制。
- 用户单独问单个字段 → 当场按本规范出 + 给字数核对。
- 常见字段弹药映射：非销售实习经历=星屿传媒(内容运营)+衡广文化(项目助理)的非商务段；校园实践=星芒科技校园俱乐部+校就业促进会部长；自我评价=母版 06 对应岗位版压缩。
