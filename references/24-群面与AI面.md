# 群面与 AI 录制面试方法论

> 适用：① **群面（无领导小组讨论 LGD）**——多人同场、面试官旁听记录得分点；② 大厂校招**录制式 AI 面试**——无互动、靠一次答对。真人单面见 `22-人设卡.md` / `21-出题规则.md`。
> 说明：本章案例公司名均为**化名**、数值为**示例值**，实际内容一律从 `[档案]` 取，不照抄。

## 群面（无领导小组讨论 LGD）专项

> 适用：管培生 / 大厂培训生 / 销售 / 运营等群面。多人同场，面试官在旁只记得分点，不互动。

### 角色与定位（不硬抢 leader，抢「有效角色」）

| 角色 | 典型表现 | 加分点 | 风险 / 扣分 |
|---|---|---|---|
| 破冰 / 框架者 | 开场定议程、给讨论框架 | 结构感、控场 | 只定框架不参与 = 空 |
| Leader（协调者） | 分配时间、推动收敛、拉回跑题 | 领导力、结果导向 | 抢话压人 = 减分 |
| Timekeeper | 报时、切阶段 | 时间管理 | 只报时无观点 |
| 观点贡献者 | 给关键论据 / 数据 / 反例 | 实质、差异化 | 只顾输出不听人 |
| 总结者 | 收尾成共识、结构化陈述 | 归纳、表达 | 抢总结但没内容 |

> 定位原则：先判断本场缺什么角色再补位，不盲目抢 leader；「无效 leader」不如「高质量贡献者」。

### 评分维度（面试官打分口径）

| 维度 | 看什么 | 高分解法 |
|---|---|---|
| 实质贡献 | 观点是否有信息量 | 每轮发言带论据 / 数据 / 反例，不重复别人 |
| 逻辑结构 | 会不会拆框架 | 开场给「判断标准 + 讨论框架」 |
| 协作与倾听 | 是否回应他人 | 点名接话「顺着 X 的…补充」 |
| 领导与推动 | 能否收敛共识 | 中段推动「剩 X 分钟，我们定 A/B/C」 |
| 时间管理 | 节奏 | 主动报时、及时收敛 |

### 话术模板

- 破冰定框架：「我建议先用 2 分钟各自亮观点，再按『成本 / 可行性 / 风险』三条标准收敛，最后 5 分钟定结论，可以吗？」
- 接话补位：「顺着刚才 A 说的成本问题，我补一个数据 / 反例……」
- 推动收敛：「时间剩 5 分钟，我们对齐一下：多数倾向方案二，卡点是预算，这样定行不行？」
- 拉回跑题：「这个点很重要，但先记下来，我们把主线拉回……」
- 总结收尾：「我们组的结论是……依据是……遗留风险是……」

### 练习方法

1. 3 人一组模拟 30 分钟 / 题（如「校园推广预算怎么分」「新产品先打哪个渠道」），第三人只记「谁说了得分点」。
2. 录音回听，数：有效发言次数 / 是否被打断后失位 / 有没有推动收敛。
3. 固定练 2-3 个高频题型：排序类（优先级）、方案类（策划）、资源分配类。

## AI 面机制与打分（机器初筛 + 人工复核）

| 特征 | 要求 |
|---|---|
| 限时 1-3 分钟/题，倒计时不可暂停 | 60-90 秒内说完，超时被切断=丢分；先练时长 |
| 无真人互动、无追问 | 回答自包含：结论先行 + 完整 STAR，自己补全背景 |
| AI 初筛（语义/关键词/结构评分）| 第一句点题放 JD 词；结构「先结论后展开」 |
| 5-8 题题型固定 | 可预测：自我介绍→行为题→情景题→岗位动机→追问 |
| 在线工具可用性因系统而异 | 按不可用准备（离线背熟框架） |

## AI 面 7 题预测框架 + 题眼

| 题 | 题眼（在测什么） | 结构 |
|---|---|---|
| 1 个人介绍 | 自我认知 + 关键词命中 + 时长 | 一句话定位→3 段实证（技术/商务/市场）→为什么适合 |
| 2 求职最看重哪些因素 | 价值观 + 稳定性，**必须举例** | 3 因素，每个=观点+真实例子+「这岗位满足」 |
| 3 为什么选这岗 | 岗位认知深度（是不是知道本质）+ 接受度 | 认知（知道是销售）→三匹配点→接受实习留用机制 |
| 4 最大突破 | **颗粒度**（能否讲到方案层） | 突破是什么→难在哪→分步怎么做（4 步）→改变了什么 |
| 5 追问 | 回答自洽性 + 细节经得起挖 | 只补细节不重复主线；不会的诚实+给验证路径 |
| 6 最艰难时刻 | 抗压真实性 + 「回头看」反思深度 | 艰难→真实情绪→应对方法→三层视角（当时/现在/未来） |
| 7 棘手情况 | 方法论 + 协作成熟度 | A 优先级（影响面×时间约束排序）/ B 沟通（对齐目标→信息同步→主动暴露风险） |

## AI 面高频追问预案（题 4/5 必背）

| 追问 | 答案要点 |
|---|---|
| 代码是你写的吗？AI 写了多少？ | 「代码是 AI 敲的，设计是我拍的」——实现层 AI 辅助多，架构/方案/测试场景设计是本人定 |
| 这批测试用例谁写的？ | 测试场景与边界条件本人设计，框架 AI 搭——测试是验证 AI 产出正确性的手段 |
| 账号本身粉丝多吧？（百万播放） | 不否认账号基础，强调增量：选题方法（热点+情绪）+数据复盘驱动迭代 |
| 你最大的缺点？ | 真实短板+已开始改进（如「习惯一个人做完→协作沟通主动不够→已改」），不硬编完美主义 |
| 被拒 50 次还能坚持吗？ | 概率+方法论：把被拒当数据复盘迭代；用高压统筹经历实证 |
| 你英语一般怎么办？ | 如实+提升计划；产品价值为主，技术理解力补语言短板 |

## AI 面行为题素材选择原则

- 题 4 最大突破：选「突破感最强 + 好讲深度」的项目（示例：从零上手某项新技术 → 攻克一个具体工程难题），不选「顺风顺水」的经历
- 题 6 最艰难时刻：选真实焦虑过的攻坚期（案例：连续几天进度为负），诚实说情绪（睡不着），再给方法（拆问题→查资料→测试锁死）
- 题 7：备好优先级 + 沟通两个故事，现场选最贴题的（示例：多场线下活动排期 / 跨团队成片交付）
- 所有数字先统一口径（测试数量 / 提效幅度 / 活动场次 / 合作家数 / 周更篇数等），追问来了才不乱。

## AI 面口语化铁律（录音面试最易翻车处）

- 答案必须「像说的不像写的」：短句、口语连接词、句间停顿；数字自然带出
- 背熟后出声练 3 遍 + 录音回听，卡壳处 = 薄弱点
- 环境：安静、正面光、纯色背景、设备充满电提前测摄像头麦克风
- 着装：商务休闲以上（衬衫/Polo），不穿卫衣；看镜头不读稿
- 每题答完停顿 1 秒再点结束，避免切掉尾音
