## 一、岗位本质（面经一手实证，HIGH）

- **技术产品商务培训生 ≈ To B 云销售**：不是运营/产品岗，核心 = 卖云（IaaS/PaaS/SaaS/AI 服务）。
- 实习日常流程（公开面经社区 2024-11 离职实习生亲述）：根据分配的公司名单 → 摸排基本信息/业务状况 → 查找关键人物（CEO/技术总监）联系方式 → **电话商务建联（大量被拒接/挂断，需心理强大）** → 深入了解对方 IT 体量、云产品使用、月/年消耗 → 预约线上会议/线下拜访 → 建联不上需**陌拜**。
- 强度：会议多（每日一日会/每周周会+培训）；无硬性工时；「更适合精力旺盛的同学」。
- 培养：**实习期间需自学并考过云从业者认证** + 自学该厂商自研产品； mentor 1v1 无私带教；实习生需自己积极争取推进销售进度。
- 留用机制（JD 原文）：**实习留用 = 拿正式校招 offer 的唯一途径**，至少 1.5 个月实习。投此类岗前必须先问用户能否接受实习留用 + 异地 base（该厂商岗位多在深圳/北京，示例）。

## 二、群面新题型（2026-04 公开面经，HIGH——今年最新）

- 题型：**AI 云产品解决方案 + 获客计划题**（AI 涉及多；**全程不限任何在线工具**，可抬头 AI 辅助构思）。
- 流程：① 12min 读题（题目开放、限制少，需共享屏幕）→ ② 2min 个人陈述（**时间到直接打断**，绝大多数人讲不完）→ ③ 1min 回答面试官提问（问题有简历针对性但非复述简历，基本都涉及 AI）→ ④ 1min 抢答（**限 3 个人**）。
- 复盘要点：用 **2B 销售方法论直接套**（SPIN/FAB/客户分层）；核心考察 = **2min 时间控制 + 回答逻辑性**；面试官提问可能讲一大段 → 关键词捕捉能力重要。
- 题库设计启示：JD 含群面环节 → 题库必须加「群面专项」模块 + 可复用陈述框架（痛点 30s → 解决方案 45s → 获客 30s → 预期 15s），练时间控制。

## 三、To B 销售方法论（群面必考，MEDIUM 综合）

1. **SPIN 提问法**：Situation（背景）→ Problem（问题）→ Implication（牵连）→ Need-payoff（需求回报）；用提问挖客户需求。
2. **FAB 法则**：Feature（特性）→ Advantage（优势）→ Benefit（客户利益）；讲产品按此结构。
3. **客户分层/商机分级**：按体量/消耗/决策链分层对应不同投入；获客先锁头部试点再辐射长尾（面试答案比均匀撒网高一个段位）。
4. **解决方案式销售**：从卖产品转向卖场景方案（行业解决方案）。

## 五、云厂商从业者认证（JD 加分项 + 实习必考，HIGH 官方页核实，示例）

- 官方培训认证页（示例检索路径）：认证体系分层：**从业者认证**（面向学生/个人开发者，验证云计算基础知识 = JD 加分项对应级）/ 开发工程师 / 交付运维 / **销售&售前认证**（面向销售及售前，与岗位直接相关，入职后进阶）/ 架构师 / 产品&解决方案。
- 报名流程：注册云账号 → 个人实名认证 → 选科目「立即购买」→ 预约 → 考试。
- 规则：理论考试 24h 前可免费改期/取消（上机 72h）；购买 5 天内未预约可退款。
- **建议策略**：投递前考掉从业者认证（缺口变加分 + 实习期减负），费用未核实（推测几百元级，示例）。
- 面试追问口径：若未考 → 诚实 + 给行动路径（已调研官方流程/计划报考），不要硬编。

## 六、匹配画像与简历选材（技术×商务双栖）

- 差异化定位：这类岗候选人多为商科/销售背景，**「懂技术（真实项目）+ 懂商务（渠道/代理经历）」双栖稀缺**——简历主打能「听懂客户技术需求 + 主动拿商机」。
- 选材：技术项目（全栈/开源项目 = 技术理解力证据，TeaBox 型）+ 商务经历（线上引流/线下代理/合作商招募 = 原样对应 JD「直销+渠道分销」）+ 主动出击型经历（主动找厂商谈合作 = 商机挖掘人格）+ 高压对接经历（对接 N 家企业 HR = 电话建联抗压实证）。
- 弃材：内容岗噪音（调色/爆款文案/自媒体接单）、游戏经历（非游戏向 JD）。
- 红线：无云实战经验**不写进简历**（无「云/云计算经验」表述），云知识放面试补课项；「本地 vs 云」设计权衡（如本地优先素材工具）可作理解云的切入谈资。
- 技术面翻车点：vibe coding 项目必准备 AI 分工说法（架构/机制自己主导、实现 AI 辅助），且能**面向非技术客户讲清产品价值**（先痛点场景再特性→优势→利益）。
