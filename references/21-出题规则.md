# 出题规则

> 用途：Step 3 从弹药库生成定制题库（普通面/压力面两版）。
> 铁律：**每题必须能说出出处**——母版哪条经历 / JD 哪条要求 / 情报哪条结论。说不出出处的题不写。

## 一、题库结构（单场 8-12 主题，按序推进）

| 模块 | 题数 | 内容 | 主要出处 |
|---|---|---|---|
| ① 开场 | 1 | 自我介绍（要求限定：1 分钟 / 说简历上没有的） | 定制简历 |
| ② 经历深挖 | 2-3 | 每段经历 1-2 题，含贡献边界、方法、数字验证 | 母版 + 定制简历 |
| ③ 项目深挖 | 1-2 | 项目 STAR + 难点 + 复盘 | 母版项目 |
| ④ 岗位认知 | 1 | 对岗位的理解、核心指标、工具掌握 | JD 必须项 + 行业情报 |
| ⑤ 情景题 | 1 | 岗位真实场景：给你一个任务你怎么做 | 行业情报 + 岗位方法论 |
| ⑥ 软性信号 | 1 | ownership / 抗压 / 协作 / 结果导向 | JD 隐藏信号 + 母版标签 |
| ⑦ 缺口题 | 0-2 | JD 要求但母版薄弱的能力（普通面引导补强 / 压力面试探） | 定制阶段 缺口清单 |
| ⑧ 反问环节 | 1 | 「你有什么想问我的」（普通面必问；压力面可选） | — |

> 注 1：自我介绍（①）无完整 STAR，复盘时不评 Structure，只评 Relevance / Differentiation / Substance。
> 注 2：主问题不超出题库；面试中允许临场追加追问（按追问链或按回答暴露点即兴下钻），临场新增的主问题不写入复盘扣分依据。
> 注 3：**总量控制 8-12 主题**（上表各模块上下限相加即 8-12）。时长不足时的**裁剪优先级**：先砍 ⑦ 缺口题 → ⑤ 情景题 → ⑥ 软性信号 → ③ 项目深挖至下限；**① 开场、② 经历深挖（至少保留 2 题）、⑧ 反问不砍**。裁了哪块必须在题库头部**显式声明（裁了哪块 + 为什么）**，不得静默省略。

## 二、套题 vs 情景题判定（防误伤）

- **泛化套题（禁止）**：无出处、不绑经历/JD/情报的孤立题（如不问背景直接问「你最大的缺点是什么」）。判定：换任何候选人、任何岗位都能原样问 → 禁。
- **岗位情景题（合法）**：绑定岗位真实场景的题（如「冷启动账号 30 天怎么做」）。通过标准：① 场景来自 JD 职责或行业情报；② 追问必须拉回用户经历（「你实习里哪件事证明你能做到」）。缺一 → 不写入题库。

## 三、出题来源优先级（取题顺序固定）

1. **定制简历**（面试官眼前唯一的书面材料）——最先取材，所有主问题从这里起
2. **母版细节**（定制简历没写的深层弹药：难点与解决、成果数字、挖掘记录）——追问用
3. **JD 必须项**（JD 明确要求的硬能力，逐条映射到经历或诚实标记「无对应」）
4. **缺口清单**（定制阶段 Step3 产出；普通面 = 引导补强题，压力面 = 试探题）
5. **行业情报**（公司/行业/岗位知识题，如「对我们账号矩阵怎么看」）
6. **隐藏信号**（ownership / 抗压 / 协作，从母版标签里找证据链；母版标签体系：leadership/technical/results/collaboration/content/sales/product，另可引用 06_自我评价 各版本作证据）

## 四、追问设计（每个主题配 2-3 层追问弹药）

主题定好后，为每个主题预写追问链（压力面/普通面两套问法）：

```
L1 事实层：验证基本信息（时间/角色/做了什么）
L2 贡献层：拆「我们」→「你」（压力面必问）
L3 方法层：怎么做的？用什么工具/方法？卡在哪？
L4 数字层：基数/口径/对比/趋势（压力面必问，普通面可选）
L5 反思层：如果重来一次，哪里会做得不同？（普通面偏好，压力面少用）
```

> **与 46 视角 3 层号对齐**：`46-质检与复审.md` 压力面视角写「追问链到第 3 层（事实 → 贡献边界 → 数字口径）」，其「3 层」实指本表 **L1 → L2 → L4**（跳过 L3 方法层，非连续三层）；简历复审只取高危点走这三层，模拟面试才走完整 L1-L5。

**示例**（素材：经历 01 Agent 工作流提效）：

| 层 | 普通面问法 | 压力面问法 |
|---|---|---|
| L1 | 「这段经历什么时候开始的？」 | 「入职多久开始做这件事的？」 |
| L2 | 「你在里面主要做了什么？」 | 「这个是你自己牵头，还是别人安排你做的？贡献边界在哪？」 |
| L3 | 「当时怎么想到用 Agent 的？」 | 「搭的过程中卡在哪？最后版本迭代了几轮？」 |
| L4 | 「提效 100% 是怎么算出来的？」 | 「口径给我：对比基线是什么？日均 2 篇是怎么统计的？样本期多长？」 |

## 五、两版题库差异总则

| 维度 | 普通面 | 压力面 |
|---|---|---|
| 问法 | 开放式陈述：「介绍一下…」 | 逼问式/质疑式：「你简历写…怎么证明？」 |
| 追问深度 | L1-L5 全走，节奏温和 | 直奔 L2+L4，打断铺垫 |
| 缺口处理 | 引导补强（「这块你打算怎么补？」） | 连续下钻直到露出不会（真实面试官的戳法） |
| 数字要求 | 问到有数字即可 | 逼到口径/基数/对比，答不出不放过 |
| 时长 | 40-60 分钟 | 30-40 分钟（更密） |

## 六、STAR 评分口径（复盘用，出题阶段先定好每题考察点）

- 每主题标注考察维度：**Situation（背景）/ Task（任务）/ Action（行动）/ Result（结果）** 哪个是重点，以及对应 `23-复盘规则.md` 的 5 维中哪几维。
- 出题时即记录「本题理想答案要点」——复盘时对照用户的实际回答找差距（**理想要点只用于复盘对比，不用于面试中提示**）。
- **理想答案要点铁律：只能来自母版经历 / JD / 情报；无据可依时写「待情报补充」，禁止自行编造**。

## 七、验收清单（Step 3 产出前核对）

- [ ] 8-12 主题；模块覆盖 ①-⑧（⑦ 可 0 题；时长不足按注 3 裁剪优先级裁剪，并在题库头部声明裁了哪块）
- [ ] 每题出处可追溯（简历/JD/情报/母版）
- [ ] 每主题配 2-3 层追问（两版问法）
- [ ] 每主题标注考察维度 + 理想答案要点
- [ ] 无泛化套题（「你最大的缺点是什么」这类必须绑定具体经历出处）
