# 简历 AI 味检测清单 + KH（keyword-stuffing 风险）

> 2026-09-04 新增。来源：agent 调研（Willo 2026 n=100+：14% 招聘团队部署 AI 检测器；JPMorgan/Deloitte；AI 简历检测研究）+ 用户「不要 AI 味」要求。
> 用法：每写/改一条 bullet 或自我评价之前，对照一次；是红线项直接删改。
> **本文件是禁词/AI 味检测的唯一权威表**；`40-格式红线.md §2` 与 `16-自我评价.md §四` 仅指向本文件，不再各写一份禁词。

## A. AI 高频套话检测（命中即打回）

**动词/名词空壳**（无事实支撑的抽象词）：
- 显著提升、大幅优化、有效赋能、降本增效、多维、闭环、抓手、颗粒度高、强矩阵、商业闭环、降维打击、复盘驱动、方法论复用
- excellent communication skills、team player、results-driven、self-starter、passionate、detail-oriented（英文原词）

**简历模板腔（HR 免疫 + AI 生成特征）**：
- 具备 X 能力 / 拥有 X 经验 / 熟练掌握 X / 积累了 X 经验
- 覆盖…等核心功能 / 全流程支持 / 独立完成 XX 多个模块
- 将 X 打法提炼为 / 沉淀了 X 方法论 / 形成 X 体系

**多余修饰**（删掉不影响事实的）：
- 非常、很、一定、极好、出色、高效、充分

## B. 文体检测（命中即改）

- 每条 bullet 句式是否雷同（都是「动词+名词+结果」同构）？→ 长短句交错
- 是否连续 3 条以「统筹 / 主导 / 负责 /提升」开头？ → 换动词
- 是否出现「门道 / 摸进门 / 扛得住 / 我得说 / 坦白讲」等口语轻浮？ → 删
- 是否整段只有一个长句分号到底？ → 拆 2-3 句，留口语节奏

### B2. 自我评价专属三判据（2026-09 单次实战新增，被打回「不是重复一遍简历」）

自我评价是 AI 味重灾区，因为它天然容易写成「履历压缩包」。出稿前逐条过：

| # | 判据 | 不过关的处理 |
|---|---|---|
| 1 | **去重测试**：这条信息简历正文写过吗？ | 写过 → 删，只留简历没有但 H R 想知道的 |
| 2 | **可移植测试**：换个人名照样成立吗？ | 成立 → 重写，塞进只有本人能提供的东西 |
| 3 | **稀缺性测试**：同批应届生里这点稀缺吗？ | 不稀缺 → 换一条，把最稀缺的放第一句 |

**手法提示**：口语短句是**人味的来源**（「我算一个」「都由我跟」），与「口语轻浮」（门道/摸进门）是两回事，前者鼓励、后者删。数字写起点优于写百分比（「日均 2 篇提到 4 篇」> 「提升 100%」）。

## C. 事实与口径（命中即打回）

- 数字能说出起点、周期、口径吗？（「提升 30%」→ 从 X 到 Y，统计范围、对比基准）
- 能面试当场讲故事吗？（条 bullet 对应一个可复述的具体场景）
- 有没有哪怕一个「简历里没说、LinkedIn/网申/作品集写得不一样」的字段？ → 统一后再投
- 自我评价首句是否把 ATS 要抓的岗位词埋进去了？

## D. 投递前关键词密度检查

- JD 给出的核心关键词（软件/工具/岗位名）按 `14-改写规则.md` 的密度口径控制（堆砌会被 LLM 筛选降权）。
- 关键词永远用 **JD 原词**（JD 写「私域运营」就写「私域运营」，不写「社群维护」）。
- 凭履历写「精通 XXX」，但母版没证据 → 不进简历，进缺口清单。

## 判断

- A/B 命中任意一条 → 先改再出稿；
- C/D 命中 → 与用户核对（真实数据/口径/关键词选择），确认后定稿。

> 用法：Step 5 自检时逐条过；也可配合「面试追问测试」（对每条 bullet 自问「HR 追问的第一个问题我答得出吗」）。
