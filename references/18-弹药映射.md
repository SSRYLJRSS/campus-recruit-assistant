## 2. 五类岗位的固定选材表

### 销售类 ToB
- **选**：E2（商务全流程=线索→落地+商务SOP）、P1（主动谈判）、E3（对接HR/宣讲）、P5（技术理解+能讲清产品=ToB 销售需懂技术）
- **弃**：E1（内容产出，非销售岗信号）、P3/P4（内容流派方法论）。拍摄/调色/爆款全部不写。
- **自评**：放「技术×商务双栖」——能听懂客户技术需求，又能讲清产品价值；提主动出击（主动谈星芒科技合作）、交付收尾（数十场活动、50+企业）。
- **反例**：若把「百万妆账号」写进 ToB 销售自评 → 被 HR 识别为内容赛道，判错方向。
- **P5 三档适用范围**：P5 技术栈启用按三档规则（技术产品岗全启用 / AI 应用岗保留段落去技术栈 / 门店零售实业一律砍，见 `15-写作总纲.md` §三.4）；ToB 销售只取「能讲清产品 / 技术理解」的段落，不展开实现层技术栈。

### 销售类 ToC
- **选**：E1 里的 C 端内容理解（百万粉财经济）+ E2 商务渠道 + P5（可选）+ E3（大规模客群）+ P1（主动PK）
- **弃**：ToB 阶段式技术内容（某桌面应用不写或简述）；拍摄剪辑、达芬奇不提。
- **自评**：base 杭州、熟悉本地高校/年轻消费群体（零售/消费场景）；专注拿结果、「目标导向」而非「懂技术」。

### 线下业务运营
- **选**：P1（0-1落地+线下活动操盘）、E3（大规模 3000 人社群+宣讲会现场）、E2（标准化 SOP+飞书）、E1 的复盘循环
- **弃**：toB 双身技术画像、达芬奇/拍摄特多（除非岗需要内容）
- **自评**：强调从 0 到 1 组织、流程标准化意识、服务大群体（3000 人）的状态管理。

### 新媒体运营
- **选**：E1 全量（内容创作+爆款+热点+数据复盘+分镜/剪辑+AI 工作流）、E2（拍摄/后期/脚本）、P3/P4（方法论开源）
- **弃**：E3 可以写少量（社群），P5 的小技细节（vibe coding、测试数）只当「技术理解」不展开；商务全流程（ToB 视角）可弱化
- **自评**：放「内容-数据-技术」三合一：能写爆款、能复盘、能用 AI 提效、会拍摄剪辑调色一条龙；有开源方法论背书。

### 用户社群运营
- **选**：P1（300+核心社群+活跃机制）、E3（大规模社群+服务）、E1 的「用户偏好洞察」（数据复盘、热点响应）、E2（缩短新人周期）
- **弃**：拍摄剪辑/达芬奇（社群的用户面）；P3/P4 技术性不写
- **自评**：放「规模用户运营 + 高活跃（300+）+ 好感对应」。

### 电商 / 平台运营（2026-09-11 新增，倍清日化·跨境电商运营首例）

- **选**：E2 的「飞书素材自动标记入库系统 + 素材分类编码规则」（→ 商品素材资产管理，**头号弹药**）、E2 的商务全流程与摄制团队对接（→ 对接平台/经销商三方关系）、E1（内容素材产出 + 数据监控复盘 + 流程提效）、P1（0→1 + 社群用户运营 + 活动落地）、E3（对接 50+ 家企业 = 外部关系维护；大规模社群 = 顾客管理）
- **弃**：P5（技术开源弃用线，**延伸适用于实业/消费品制造**）、**排球队**（本岗无运动要求，启用只会稀释电商主线——与悦动健身/动派体育的处理**相反**）、达芬奇/调色/分镜/稳定器（影视后期标签 = 赛道噪音，电商要的是图文素材不是视频后期）、自媒体接单、ETF 实盘
- **自评**：放「素材 + 数据」双能力；首句**不放「百万粉/爆款」内容赛道标签**（避免 HR 判成"做新媒体的人来投电商"），改用「内容素材产出、数据跟踪、外部合作对接」的中性口径；末句点名电商动作（选品、备货、数据跟进）+ 城市
- **⚠️ 反幻觉红线**：电商核心动作（商品管理、产品上架、库存备货、主图/标题优化）若母版零证据，**一律不写**，只改口径不增事实
- **⚠️ 岗位性质预判（需核实）**：TEMU/SHEIN 常为**托管模式**（以平台最新规则与 JD 为准，投前核实）；供货商侧实际权限 = 选品提报/寄样审版/备货/素材/数据跟进/对接买手，平台掌握核价、定价、投放、售后 → 面试前必须先补此认知，避免按"传统店铺运营"理解 JD 而答错

## 3. 特殊决策点（遇到就问）

1. **要写排球吗**（男排核心、2025 省第六、2026 省第八）：销售 ToC / 线下运营这类「零售/快消/体育」岗直接加分 → **默认加上**（放自评或经历）；纯内容/纯技术岗 → 一般不加。
   - 注意：自评里写了「省级赛事」必须在正文有排球经历，否则悬空引用（2026-09-04 ToC 事故）。
2. **某桌面应用怎么写**：产品/技术/ToB 岗 → 完整展开（懂技术的销售）；新媒体/社群 → 只在技术能力句带过或删。
3. **「百万粉丝账号」写不写**：内容/新媒体岗 → 大加分；销售 ToB/ToC（非内容）→ 慎用，避免 HR 判错赛道；实业/制造 → 必须删。
4. **电商/平台运营岗**（2026-09-11 倍清日化定案）：见第 2 节「电商 / 平台运营」。要点——该桌面应用/net-alert 弃用线延伸至消费品实业；排球本岗**不启用**；「百万播放」可留在经历 bullet（电商含内容营销职责）但自评首句不放内容赛道标签。

## 4. 弹药「可迁移包装」参考（照抄即可）

- 商务全流程 → 「从线索获取到合作落地形成闭环」 / 「覆盖全部流程」
- 社群 300+ → 「高活跃核心社群；打造日常活跃机制与活动转化」
- 宣讲会 → 「对接企业 HR 落地校园宣讲会」「从邀约到待客全流程」
- 效率提升 → 「流程优化实现效率提升 30%-100%」（E1/E2 的 100% 可延伸）
- 0 到 1 → 「从 0 到 1 主动促成企业合作（星芒科技），落地首届校园俱乐部」
- 数据复盘 → 「通过数据复盘定位内容/活动表现不佳的原因，反向制定选题/动作」
- 拍摄剪辑 → 「上手拍摄（相机/稳定器）+ 后期（达芬奇/剪映）」

## 5. 反面红线（冲击过去踩的）

- **悬空引用**：自评引用的每个数字/事实，正文必须有对应经历（2026-09-04 ToC「省级赛事」事故）
- **跨域不剔**：投制造/实业时把内容赛道的爆款标签带进自评 → HR 判断错方向
- **效率**：全文每岗的 bullet 数不泄（每段 3-5 条），通用版时间倒序
- **「Skill」不写「SOP」**：开源部分永远用「Skill」
