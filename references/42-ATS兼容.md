# ATS 兼容规则（2026 实测版）

> 2026-09-04 新增。来源：四路 agent 调研汇总（ATS 解析器乱序 1/3、表格是首要解析错误源、语义匹配量化等）+ 新版方法论。
> 适用：Step 5 自检；用 MD→PDF 拦截环境。

## 核心结论（2025-2026 对比旧认知）

| 旧规则 | 2026 状态 | 说明 |
|---|---|---|
| 堆关键词 | ❌ 反效果 | LLM 语义匹配可识别同义词；单词密度 >5 被降维 |
| 精确关键词匹配 | ⚠️ 部分失效 | 语义匹配（向量相似度）已在多数 ATS 叠加 |
| 强制一页 | ✅ 仍成立（应届） | 应届生保持在 1 页 |
| 证件照 | ⚪ 默认不放 | campus-cn 默认不放；仅国企/银行/形象岗或用户明确要求时，按 `40-格式红线.md` §3 参数放 |
| 自我评价栏 | ✅ 该写 | ATS 抓词重点；重要的是有事实、非空话 |

**2025-2026 语义匹配量化（外部调研，非权威仅佐证）**：头部大厂 ATS 按简历与 JD 的向量余弦相似度排序，约前 20-30% 进 HR；岗位画像权重示例：必备技能 45% / 加分项 25% / 软技能 15% / 业务匹配 15%。结论：从 JD 抽「实体 / 关系（搭建·优化·集成·重构）/ 属性」三类词自然嵌入，比机械堆词有效。来源：阿里云开发者《大厂 JD vs ATS 后台扫的——2026 隐形规则》(2026-08-11)，详见 `_work/research-digest.md` S7。

## 硬性检查清单（Step 5 逐条过）

- **单栏无表格 / 文本框 / 双栏**（表格 = 解析错误首要原因；当前 WPS 模板单栏天然合规）。
- **标题用标准词**：实习经历 / 项目经历（语义 Standard Section Heading）；campus-cn 无独立教育模块、学校专业并入头部第三行，campus-tech/intern 按 profile 可保留教育背景/技能段。
- 关键信息（联系方式）放正文顶部，**不进页眉页脚**。
- 导出「可选中文字」的 PDF 或 DOCX（禁用扫描图 / Canva 矢量图）。
- 日期统一 `YYYY.MM`（如 `2026.05 - 2026.08`），避免纯数字歧义。
- 姓名 / 电话 / 邮箱 / 学校 / 专业，每项独立成行（解析友好）。
- 文件命名：`姓名-岗位-届别.pdf` 或既有 `CV_公司_岗位_YYYYMMDD`，≤50 字符、无空格特殊字符。
- 缩写首次出现带全称：「搜索引擎优化（SEO）」「A/B 测试」。
- 不看：不要用隐藏白字 / 透明文字 / 页脚堆关键词——被识别 = 直接拉黑。

## 语义化修饰注意

- 关键词用 JD 原词（密度口径见 `14-改写规则.md`）。
- 自我评价首句埋岗位关键词（ATS 抓首句）。
- 每条 bullet 有动作+结果（供 LLM 语义打分），避免只有职责词没有结果词 → 被归为「职责罗列」。

## 投递动作规范

- 邮件主题：`【岗位】姓名+亮点`（或按 JD 要求）。
- 附件名与人名一致，PDF 优先（ATS 可解析、不跑版）。
- 每次投递后在台账记录：公司 / 岗位 / 日期 / 简历版本 / 渠道 / 状态。
